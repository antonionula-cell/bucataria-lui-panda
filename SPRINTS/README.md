# Sprinturi — Bucataria lui Panda

Aici stau toate sprinturile proiectului, ca sa putem lucra si de pe telefon (Claude Code pe mobil citeste repo-ul, nu memoria de pe laptop).

## Cum folosesti

- Spune-i lui Claude: **"hai la Sprint Promo 1"** (sau numele oricarui fisier de aici). Claude citeste fisierul, iti spune ce e de facut si lucreaza pe un branch nou.
- Un sprint nou = un fisier nou: `sprint-<nume>.md` (ex. `sprint-plata-netopia.md`).
- Cand se termina o sarcina, bifeaza `[x]` in fisier, in acelasi commit cu schimbarea.

## Legenda

- `[ ]` de facut
- `[~]` inceput / partial (detalii langa)
- `[x]` gata
- `[?]` de verificat (exista ceva in cod, dar nu e confirmat ca merge cap-coada)
